# 칭찬고래 (gorae-bot)

유료 "칭찬고래" 슬랙 앱을 대체하는 사내 봇. **Vercel Functions + Vercel
Postgres** 위에서 돌아갑니다. Slack 메시지가 올 때만 함수가 실행되는
이벤트 기반 구조라 상시 켜둘 서버가 필요 없고, 회사에서 이미 쓰는 Vercel
계정에 그대로 올리면 되어 새 계정/새 결제 수단이 필요 없습니다.

## 동작 방식

- 채널에서 `@사람 🐋`처럼 멘션과 고래 이모지를 같이 보내면 기록됩니다.
- 한 메시지에 멘션이 여러 명이면, **멘션된 사람 각각**이 그 메시지의 고래
  개수만큼 받습니다. (예: `@A @B 🐋🐋` → A, B 각 2개씩, 발신자는 하루 한도에서
  4개 차감)
- 발신자는 하루 최대 5개까지만 보낼 수 있습니다. 초과하면 아무것도 기록되지
  않고, 보낸 사람에게만 안내 메시지가 갑니다(채널엔 표시 안 됨).
  - **`ADMIN_USER_IDS`에 등록된 관리자는 이 하루 한도가 적용되지 않습니다.**
- `/dashboard`에서 이번 달 보낸/받은 전체 랭킹을 상시로 볼 수 있습니다. 이름/
  프로필 사진과 함께 표시되고, 월 선택기(달력)로 지난 달도 넘겨볼 수 있습니다.
  Slack 계정으로 로그인해야 하고, `ADMIN_USER_IDS`에 없는 사람은 로그인해도
  접근이 거부됩니다.
